# 知时 · 智慧自习室预约与管理系统

本机课堂演示版，采用 Flask、Flask-SQLAlchemy、SQLite 和本地响应式页面。无需 Docker，不连接 Dify、外网服务或校内认证。

## 启动

在项目目录打开 PowerShell：

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m flask --app app init-db
python -m flask --app app run
```

浏览器打开 http://127.0.0.1:5000 。首次运行会自动创建 `instance/studyroom.db` 并填充演示数据；`init-db` 可补齐演示账号和样例房间，不会清空现有预约。

| 角色 | 账号 | 密码 |
|---|---|---|
| 学生 | `student` | `student123` |
| 管理员 | `admin` | `admin123` |

关闭终端服务可按 Ctrl+C。数据文件保存在 `instance/studyroom.db`，重启后仍保留。

## 已实现

- 学生/管理员账号登录，密码安全哈希；角色保护与学生本人记录隔离。
- 自习室/座位维护；预约日期内的座位状态浏览。
- 整点预约、重叠冲突校验、最多两个有效预约；预约保存通过 SQLite 写锁避免双重占座。
- 开始前至少 30 分钟取消、预约开始后 15 分钟签到、结束前签退。
- 超时未签到/未签退扫描与提前 30 分钟及以上签退判违约；违约按预约幂等记录。
- 学期违约累计达 3 次进入黑名单，限制期按 7 天 × 进入次数、最多 30 天；学生端与管理员端基础统计。
- 管理员可登记使用中的预约现场违约，记录操作人、原因和时间。

## 规则与边界

预约时段按 1 小时整点单元、可提前 7 天、最多同时 2 个有效预约；这些规则按本次需求附件中的基线口径演示。投诉/评价/申诉、外部通知、统一身份认证、报表导出及线上部署不在首版范围内。需求中尚待人工确认的细则不得视作学校最终政策。

演示账号仅供本机使用。不要将本应用直接暴露到公网；共享演示前应设置随机 `SECRET_KEY` 环境变量，并更换演示密码。
