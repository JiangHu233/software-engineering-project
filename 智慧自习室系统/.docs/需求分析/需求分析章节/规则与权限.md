# 规则与权限

> 应能够查到的内容：允许、禁止及计算规则，角色及对象范围限制
> 推荐表示形式：规则表、权限矩阵，必要的决策表
> 关键内容要求：权限矩阵同时考虑角色和对象范围。例如，"教师可查看提交"还需说明是所授课程的提交，还是所有课程的提交。

## 1. 角色定义（Roles）

| 角色 | 说明 |
|------|------|
| **学生（普通用户，STU）** | 系统的核心使用者，执行预约、签到签退、查询、投诉、评价等操作 |
| **管理员（ADM）** | 自习室日常运营者，维护资源、实时管理座位、登记违约、处理投诉与反馈、管理黑名单、查看统计分析 |
| **运维（OPS）** | 系统建设与维护方，监控系统运行状态与资源占用，不参与日常业务数据的管理 |

## 2. 允许规则（Permission Rules）

| 编号 | 规则内容 |
|------|----------|
| P-1 | 学生**最多可同时持有 2 个有效预约**（含已预约未开始、已签到使用中），超出则拒绝新预约 |
| P-2 | 学生**早上可以预约当天下午及未来日期的座位**（即预约开始时间不得早于当前时间，且可提前预约未来 7 天内的时段） |
| P-3 | 学生**只能查看和操作本人**的预约、签到签退、违规记录、投诉与评价数据 |
| P-4 | 学生可在**预约时段开始前 ≥ 30 分钟**主动取消预约，取消后座位立即释放，不计违约 |
| P-5 | 学生可在**预约开始后 15 分钟内**完成签到；在预约结束前完成签退 |
| P-6 | 学生可对**已完成的预约**提交一次评价；可对管理服务提交投诉并查看投诉反馈信息 |
| P-7 | 管理员可对**全部自习室与座位**的信息（属性、状态）进行新增、修改、停用/恢复 |
| P-8 | 管理员可**查看全部预约条目**并代学生创建、取消预约（需记录操作原因，留痕） |
| P-9 | 管理员可**现场手动登记违约**（针对任意在座/预约用户），登记时须填写违约类型与说明 |
| P-10 | 管理员可处理**全部投诉**并填写反馈信息，可管理（加入/移出）黑名单 |
| P-11 | 管理员可查看**全校区全部自习室**的统计数据（柱状图、折线图），页面每 10 秒自动刷新 |
| P-12 | 运维可查看系统运行状态（CPU、内存、连接数、接口响应）与业务量级统计，**只读、不涉及个人明细数据** |
| P-13 | 黑名单用户在限制期内**禁止预约**，但仍可查询本人记录、提交投诉与申诉 |

## 3. 禁止规则（Prohibition Rules）

| 编号 | 规则内容 |
|------|----------|
| F-1 | **预约的开始时间不得是过去的时间点**；结束时间必须晚于开始时间 |
| F-2 | 同一学生在**同一时段内不得预约两个时间上重叠的座位**（两个预约的时段不得冲突） |
| F-3 | 学生（非管理员）**禁止查询、修改、删除他人的任何数据**（预约、违规、投诉、个人信息等） |
| F-4 | 状态为"维护中"或"停用"的座位**禁止被预约** |
| F-5 | 已开始且已过签到窗口（开始后 15 分钟）的预约**禁止取消**，只能按违约流程处理 |
| F-6 | **禁止代他人签到或签退**；签到签退操作人与预约人必须一致 |
| F-7 | 学生**禁止手动登记他人违约**、禁止修改本人违约记录；违约记录仅可申诉，由管理员处理 |
| F-8 | 黑名单用户在限制期内**禁止发起新预约**（P-13 除外） |
| F-9 | 运维**禁止查看学生个人明细数据**（姓名、学号、违约明细、投诉内容），只能看到脱敏后的量级统计 |
| F-10 | 管理员**禁止删除违约记录与操作日志**（只可标记为"申诉成立/撤销"并留痕），保证信用治理可审计 |
| F-11 | 对同一预约**禁止重复评价**；投诉反馈一经提交不得由学生修改 |

## 4. 计算规则（Computation Rules）

| 编号 | 规则名称 | 计算方式 |
|------|----------|----------|
| C-1 | **超时未签到违约** | 当前时间 > 预约开始时间 + 15 分钟 且 未签到 ⇒ 自动记录违约（类型：超时未签到），预约自动取消并释放座位 |
| C-2 | **未签退违约** | 当前时间 > 预约结束时间 + 15 分钟 且 已签到未签退 ⇒ 自动记录违约（类型：超时未签退） |
| C-3 | **早退违约** | 签到后签退时间早于预约结束时间 30 分钟以上 ⇒ 记录违约（类型：提前离开），早退部分座位时长回收 |
| C-4 | **手动违约** | 管理员现场登记的违约（如占座、违规使用），权重与自动违约相同 |
| C-5 | **违约计分** | 每条违约记录计 1 分，按自然学期滚动统计（学期初清零） |
| C-6 | **黑名单判定** | 学期内累计违约分 ≥ 3 分 ⇒ 自动加入黑名单，限制期 = 7 天 ×（进入黑名单次数），上限 30 天；限制期满自动移出 |
| C-7 | **座位状态实时计算** | 座位状态 = 停用/维护中（管理员设置优先）> 使用中（当前时刻落在某已签到预约区间内）> 已预约（当前时刻落在未开始预约区间内，且距开始 < 15 分钟）> 可用 |
| C-8 | **座位利用率** | 利用率 = 时段内已使用座位时长 /（可用座位数 × 时段总时长）× 100% |
| C-9 | **预约履约率** | 履约率 = 正常签到且正常签退的预约数 / 总预约数 × 100% |
| C-10 | **违约率** | 违约率 = 产生违约的预约数 / 总预约数 × 100% |
| C-11 | **统计刷新** | 数据分析页面（柱状图、折线图、统计数据）每 10 秒自动刷新一次 |

## 5. 角色与对象范围限制（Role & Object Scope）

### 5.1 学生（STU）范围限制

- **可操作**：预约、取消预约、签到、签退、评价、投诉、申诉。
- **对象范围**：**仅限本人创建的数据**——只能预约给自己（不能替他人预约），只能取消/签到/签退**本人的预约**，只能查看**本人的**预约记录、违规记录、投诉及反馈、评价。
- **数据可见范围**：座位实时状态为**全局可见**（只读，用于选座）；但座位的**历史使用记录、他人预约人身份**不可见（仅显示"已占用"）。

### 5.2 管理员（ADM）范围限制

- **可操作**：资源维护、预约条目管理、手动违约登记、投诉处理与反馈、黑名单管理、用户信息管理、统计分析查看。
- **对象范围**：**所管辖的全部自习室**（本系统为单一校区，即全部自习室）内所有座位、所有预约条目、所有使用记录、所有用户（仅业务字段，不含密码等凭证）；违约登记与投诉处理范围为**管辖自习室内发生的全部记录**，不限是否本人创建。
- **不可操作**：删除违约记录与审计日志（F-10）、修改系统级配置（属运维职责）。

### 5.3 运维（OPS）范围限制

- **可操作**：查看系统运行指标（CPU/内存/连接数/接口响应时间）、业务量级监控（当前预约数、签到数、在线用户数）、系统日志（技术层面）。
- **对象范围**：**全部系统的技术与性能数据**；**不包含**学生个人明细、违约明细、投诉内容等业务敏感数据（F-9）。
- **不可操作**：任何业务数据的增删改（座位、预约、违约、投诉、黑名单一律只读甚至不可见）。

## 6. 权限矩阵（Permission Matrix）

对象范围说明：**自有** = 仅本人创建/本人的数据；**管辖** = 所管辖自习室（本系统即全部自习室）内的数据；**全部** = 系统内所有该类对象；**脱敏** = 仅统计量级，无个人明细。

| 操作对象 \ 角色 | 学生（STU） | 管理员（ADM） | 运维（OPS） |
|---|---|---|---|
| 座位/自习室信息（查看） | ✔ 全部（只读，用于选座） | ✔ 全部 | ✔ 脱敏（量级） |
| 座位/自习室信息（增删改） | ✘ | ✔ 全部 | ✘ |
| 座位实时状态（查看） | ✔ 全部（不含占用者身份） | ✔ 全部（含占用者身份） | ✔ 脱敏 |
| 座位使用/预约记录（查看） | ✔ 仅自有的记录 | ✔ 全部自习室全部记录 | ✘（仅量级统计） |
| 预约（创建/取消） | ✔ 仅给本人创建、仅取消本人预约 | ✔ 全部（可代办，留痕） | ✘ |
| 签到/签退 | ✔ 仅本人预约 | ✘（不可代签，F-6；可现场核验） | ✘ |
| 违约记录（查看） | ✔ 仅本人的 | ✔ 全部自习室全部记录 | ✘ |
| 违约记录（登记） | ✘ | ✔ 全部用户（手动违约登记） | ✘ |
| 违约记录（删除/修改） | ✘ | ✘（仅可标记撤销并留痕） | ✘ |
| 违约申诉（提交） | ✔ 仅对本人违约记录 | ✘ | ✘ |
| 违约申诉（处理） | ✘ | ✔ 全部申诉 | ✘ |
| 黑名单（加入/移出） | ✘ | ✔ 全部用户（含系统自动加入的复核） | ✘ |
| 用户信息（查看/修改） | ✔ 仅本人（改密码、联系方式） | ✔ 全部用户业务字段（不含密码） | ✘ |
| 评价（提交） | ✔ 仅对本人已完成的预约，每预约一次 | ✘ | ✘ |
| 评价（查看/管理） | ✔ 仅本人提交的 | ✔ 全部评价（可屏蔽违规评价） | ✘ |
| 投诉（提交） | ✔ 本人提交 | ✘ | ✘ |
| 投诉（查看） | ✔ 仅本人的投诉及反馈 | ✔ 全部投诉 | ✘ |
| 投诉（处理/反馈） | ✘ | ✔ 全部投诉 | ✘ |
| 数据分析图表（查看） | ✘（可看全局空座概览） | ✔ 全部自习室统计（10 秒刷新） | ✔ 脱敏运行统计 |
| 系统运行状态（查看） | ✘ | ✘ | ✔ 全部 |
| 操作/审计日志（查看） | ✘ | ✔ 本人操作相关 | ✔ 技术日志 |

## 8. 补充说明

1. 所有拒绝类操作（预约被拒、取消被拒、越权访问）须返回明确的规则编号或原因提示，便于学生理解与申诉。
2. 管理员的代办、手动违约登记、黑名单操作等敏感动作均写入审计日志，包含操作人、时间、对象与原因。
3. 规则中的参数（15 分钟签到窗口、30 分钟取消时限、7 天预约窗口、违约分阈值 3 分、限制期 7 天）为初始配置值，可由学校管理部门在规则评审确认后调整（见《项目概述》第 5 节确认责任）。
