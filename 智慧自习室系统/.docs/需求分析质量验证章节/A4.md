## 4.5 一致性与同步说明

1. **编号一致性**：ST-01～ST-14 与《行为与状态》§2.2/§2.4/§2.5、《用户需求》用例表"状态转换"列、A3 §3.3 复杂转换条件配套表完全一致，未做改动。本表新增 ST-15～ST-20（GM-10 投诉）与 ST-21～ST-26（GM-08 座位生命周期视角）编号，须回写至对应 `.mmd` 源文件的转换标注（`docs/diagrams/GM-08-座位状态图.mmd`、`docs/diagrams/GM-10-投诉状态图.mmd`，及 `docs/graph/` 副本），回写前本表与源图存在编号缺口，属于本次验证发现项。
2. **状态与角色命名**：状态名称、执行角色（学生本人、自习室管理员、系统定时任务、系统联动）与状态图及《领域与数据》DD02/DD03/DD05/DD07 的术语一致；失败处理统一注明"状态保持"或明确的目标态变化，未把拒绝表述为转换成功。
3. **候选与待确认项**：BR-09（剩余时段释放口径）、BR-10（评价前置条件）、BR-13（投诉时限 3 个工作日）、BR-14（已反馈退回）、KQ-04、KQ-07、KQ-09 的候选值仅按 A2 原记录引用，不因写入本表转为已确认；各定稿后须同步更新本表、对应状态图及相关用例（UC-04、UC-05、UC-06、UC-07）与验收场景。
4. **联动关系**：预约单转换（ST-01～ST-07）与座位时段占用转换（ST-08～ST-12）一一联动，本表在"目标状态及业务结果"列注明联动编号；两表须同时修改，避免只改一侧。
5. **终态约束**：已取消、已签退、已违约、已评价（预约单）、已关闭（投诉单）为终态，任何转换不得从终态发起；管理员不能直接修改预约单状态，仅能通过 ST-02（代取消）与 ST-06（手动违约）受控终止（PS-03）。
