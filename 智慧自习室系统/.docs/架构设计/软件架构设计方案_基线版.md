## 2. 架构目标与约束

### 2.1 质量属性优先级

依据《质量要求》§0：数据一致性（NFR-13 座位时段唯一性）＞ 可靠性（NFR-04/05 通知不阻断闭环、定时任务幂等）＞ 安全性（NFR-07 服务端强制校验）＞ 性能（NFR-01/02/03）＞ 易用性、可维护性。

### 2.2 约束

- 课程项目：小团队、短周期、单机/内网部署与测试环境；
- 技术栈：单库关系型数据库，不引入消息队列等中间件（ADR-10 明确排除分布式锁/MQ）；
- 定时任务单实例运行（ADR-7 代价条款：多实例部署会重复触发，本期接受）。

## 3. 总体架构

### 3.1 架构风格与分层

采用**单体分层架构**（前后端分离 + 后端模块化单体）：

```
┌─────────────────────────────────────────────┐
│  前端（Web）：学生端 / 管理员端 / 实时看板页    │
│  （看板采用前端轮询刷新，见 ADR-006 / ADR-6） │
└─────────────── HTTP / REST ─────────────────┘
┌─────────────────────────────────────────────┐
│  接入层：认证过滤器（JWT 自签发，ADR-12）、     │
│  参数校验、统一异常与审计切面                  │
├─────────────────────────────────────────────┤
│  业务层模块：预约 │ 违约/黑名单 │ 投诉 │       │
│  评价/通知 │ 看板/统计 │ 认证账号 │ 基础数据   │
├─────────────────────────────────────────────┤
│  定时任务（Spring @Scheduled + 启动补偿，ADR-7）│
├─────────────────────────────────────────────┤
│  数据访问层：ORM + 数据库唯一约束防重          │
├──────────────┬──────────────────────────────┤
│  MySQL（主库）│  Redis（座位可用性缓存，ADR-5） │
└──────────────┴──────────────────────────────┘
```

### 3.2 关键架构决策（均出自 ADR，状态：已接受）

| 决策点 | 结论 | 依据 |
| --- | --- | --- |
| 座位可用性缓存 | **引入 Redis** 缓存座位可用性；需保证内存/Redis/数据库三者一致性，缓存失效或重启后可从数据库重建 | ADR-5（Q-A1） |
| 实时看板刷新 | **前端轮询，周期 1 分钟**，与后台扫描周期对齐；不采用 WebSocket；不采用 10 秒级扫描 | ADR-006（KQ-06） |
| 看板数据范围 | **按自习室查询**，本期不做全校聚合视图；接口须做权限隔离 | ADR-006 |
| 分析看板刷新 | **前端轮询**（FR-33 定 10 秒刷新）；不采用 SSE/WebSocket 推送及预聚合表 | ADR-6（Q-A2） |
| 定时任务框架 | **Spring @Scheduled + 应用启动时补偿执行**处理漏跑，补偿须幂等；不采用 Quartz | ADR-7（Q-A3） |
| 认证方案 | **自建账号体系 + 本系统自签发 JWT**；不对接 CAS/OAuth（列为后续演进，登录层预留适配器位置） | ADR-12（KQ-12） |

### 3.3 部署视图

单应用实例 + MySQL + Redis，内网/本机部署。多实例部署暂不支持（定时任务会重复触发，ADR-7；看板扫描需防重复，ADR-006 代价条款均已知并接受）。

## 5. 关键数据设计

### 5.1 座位时段占用模型（ADR-002）

- 占用记录为**离散记录**：`座位 × 日期 × 时段编号`（1 小时网格，起止以整点为边界）；
- 数据库**唯一约束**（座位、日期、时段）在存储层防止同一座位同时段重复预约，不依赖应用层区间计算；
- 跨小时预约（如 09:00–11:00）拆分为多条连续时段记录，**整体原子**（全部成功或全部失败）；
- 非整点起止（如 09:30–10:30）由参数校验直接拒绝；
- 明确不支持碎片时段预约（BR-06 本期不支持）。

### 5.2 用户状态模型（ADR-1）

- **黑名单**与**账户停用**为两个独立概念：黑名单仅限制新预约，用户仍可登录、查询座位、提交投诉；账户停用则登录即被拒绝、所有服务不可用；
- 预约校验链按此顺序设计：登录态校验 → 账户状态校验 → 黑名单校验（仅拦截创建预约）→ 时段与次数规则。

### 5.3 投诉表（ADR-004 / ADR-10）

- 状态机：提交 → 受理 → 办结，各状态记录时间戳；处理时限从**用户提交时刻**起算（3 个工作日），超时仅在统计报表体现，不自动催办；
- 在（用户 ID、内容摘要、提交时间）上建查询索引，支持 1 分钟去重窗口判断；
- 受理采用**乐观锁**：`UPDATE ... WHERE status='待受理'` + 受影响行数判断，后到者返回"该投诉已被受理"。

### 5.4 违约与黑名单（ADR-3 / KQ-03）

- 违约计数按自然学期滚动累计，学期初清零（定时任务实现）；
- 申诉成功后违约计数回退；进入黑名单后其未来预约自动取消并通知；黑名单期内再违约则延长结束时间，重复触发不重复延长（幂等）。

### 5.5 座位缓存一致性（ADR-5）

Redis 缓存座位可用性为数据库的派生视图：以数据库唯一约束为最终防线，缓存仅加速查询；缓存失效/重启后从数据库重建；并发预约以数据库约束结果为准。

## 6. 接口与关键设计

### 6.1 认证授权（ADR-12）

- 本系统自签发 **JWT**，不依赖外部身份提供方；密码哈希存储；
- 预留登录层适配器位置，后续对接 CAS/OAuth 时增加本地账号↔统一身份映射，与本期不冲突；
- 权限校验全部在服务端强制执行（NFR-07），按《规则与权限》权限矩阵与对象范围（P 规则/PS 规则）实现。

### 6.2 看板接口（ADR-006 / ADR-6）

- 实时看板接口：按自习室查询，前端每 **1 分钟**轮询，与后台 1 分钟扫描对齐（状态变化最长滞后约 2 分钟，已接受）；
- 分析看板接口：前端每 **10 秒**轮询统计查询（FR-33）；
- 接口须做权限隔离：管理员仅能查询授权范围内的自习室数据。

### 6.3 预约接口与并发控制（ADR-002 / ADR-8）

- 创建预约：参数校验（整点边界、可约天数、次数限制）→ 校验链（§5.2）→ 唯一约束写入（多时段记录同事务）；
- 取消预约：**不限次**（ADR-8），提前 ≥30 分钟（可配置），成功后释放占用并通知；
- 管理员代办预约/取消：记录操作人与原因，学生可查看（KQ-01）。

### 6.4 座位停用联动（ADR-2）

管理员停用座位时：已签到用户收到提示且签到被取消、**不产生违约记录**；使用中/未来预约被取消或拒绝并告知，不登记违约。

## 7. 定时任务设计（ADR-7）

框架：Spring @Scheduled，单实例运行；应用启动时补偿执行漏跑任务，补偿与常规执行均须**幂等**（重复执行不产生重复违约/重复解除）。

| 任务 | 周期 | 说明 |
| --- | --- | --- |
| 签到窗口超时扫描 | 1 分钟级 | 超时未签到按规则记违约（C-2 口径，KQ-03） |
| 实时看板状态扫描 | 1 分钟 | 刷新座位状态，供看板接口查询（ADR-006） |
| 黑名单到期解除 | 每日/每小时 | 到期自动解除，幂等（ADR-3） |
| 违约计数学期清零 | 学期初 | 自然学期滚动累计（KQ-03） |
| 停用座位未来预约取消 | 事件触发 + 扫描兜底 | 取消并通知（FR-06、ADR-2） |

## 8. 可配置性与运维设计

### 8.4 业务规则参数（KQ-02 已定稿，NFR-12）

以下参数**不得硬编码**，须集中配置并可修改：可预约天数（7 天）、取消提前时长（≥30 分钟）、签到窗口（15 分钟）、学期违约阈值（3 分）、预约限制窗口（7 天×次数，上限 30 天）、投诉处理时限（3 个工作日，含工作日/节假日规则配置，ADR-004）、看板轮询周期（1 分钟/10 秒）。

## 11. 风险与后续工作

- **Redis 一致性成本**（ADR-5）：若一致性维护成本超出承受范围或部署环境不提供 Redis，重开 ADR 改为直接查库方案；
- **轮询压力**（ADR-006/6）：看板客户端数量增长导致轮询压力不可接受时，重开 ADR 评估推送方案；
- **取消滥用**（ADR-8）：上线后统计人均日取消次数分布与"反复预约-取消"异常模式，若单用户单日持续 >10 次并影响利用率，重开 ADR 增加限次校验；
- **多实例部署**：当前架构单实例运行，若需水平扩展须重开 ADR-7 并解决定时任务重复触发问题；
- 文档同步：KQ-05/07/09/11 等涉及需求层的决定须同步回《需求规格说明书》§9；涉及测试的同步《分阶段实现与测试计划》（已登记于 §0 待办，不阻塞本基线）。
