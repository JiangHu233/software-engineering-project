## 0. 使用规则

1. **决定只有登记在这里才算生效**。聊天、会议口头结论不算；未同步前只能标"已决定待同步"。
2. 每条决定必须可检验（比较式 / 枚举 / 公式 / 框架名+版本），**不得写"按推荐"**。
3. **不伪造 Git 提交号**。提交标识在本文件提交后通过下一版补记，不要求文件预含自身哈希。
4. 已接受的 ADR 若被改变：**新增替代 ADR 并关联旧记录，不抹除历史**（本文件 §5 记录"待补条款"，补完后在 §4 更新状态）。
5. 本文件不重复接口契约内容，只记录"决定了什么、谁决定的、影响哪里"。
